The course

A coding agent is managed like a colleague.

Claude Code reads the project, proposes changes and runs commands. The course teaches how to give it the right context and how to decide what it may do without asking.

Who it is for. Developers and technical leads. Programming experience is required.

Duration

4 hours, in two two-hour sessions.

Format

Online or on site, at least 5 people.

Tools

Claude Pro, which includes Claude Code, installed before the first session with our help. A project to practise on is required.

Fee

From €100 per person, VAT excluded; on site plus €800. Paid in advance. All fees.

Further reading

An agent's boundary, in writing.

The reasoning on an agent's permissions is published in the article Before giving an AI agent the keys, with vulnerability CVE-2025-32711 and its sources.

The programme

Two sessions, each with a result ready for use.

First session · The agent in the project

Reading and explaining the existing code, writing the instruction file, a first change driven by the tests.

  • The instruction file: project conventions and procedures
  • Test-driven changes
  • Result: The project's instruction file and a verified change

Second session · Permissions and review

What the agent may read, run or submit for approval. Reviewing the code it produces, and an analysis of vulnerability CVE-2025-32711.

  • Read, write and execute permissions
  • Reviewing generated code
  • Result: A workflow with review and the list of permissions

At the end

The materials produced in the two sessions are exported to the participant's own files, which open in any program and can be used independently.

  • The project's instruction file and a verified change
  • A workflow with review and the list of permissions
  • The course materials
