## Un agente che scrive codice va governato come un collaboratore.

Claude Code legge il progetto, propone modifiche ed esegue comandi. Il corso insegna a dargli il contesto giusto e a stabilire cosa può fare senza chiedere.

**A chi è rivolto.** Sviluppatori e responsabili tecnici. È richiesta esperienza di programmazione.

*Il programma*

## Due incontri, ciascuno con un risultato pronto per l'uso.

### Primo incontro · L'agente nel progetto

Lettura e spiegazione del codice esistente, redazione del file di istruzioni, prima modifica guidata dai test.

- Il file di istruzioni: convenzioni e procedure del progetto
- Modifiche guidate dai test
- **Risultato:** Il file di istruzioni del progetto e una modifica verificata

### Secondo incontro · Permessi e revisione

Cosa l'agente può leggere, eseguire o sottoporre ad approvazione. Revisione del codice prodotto e analisi della vulnerabilità CVE-2025-32711.

- Permessi di lettura, scrittura ed esecuzione
- Revisione del codice generato
- **Risultato:** Un flusso di lavoro con revisione e l'elenco dei permessi

### Al termine

I materiali prodotti nei due incontri si esportano in file del partecipante, consultabili con qualsiasi programma e utilizzabili in autonomia.

- Il file di istruzioni del progetto e una modifica verificata
- Un flusso di lavoro con revisione e l'elenco dei permessi
- Il materiale didattico del corso
